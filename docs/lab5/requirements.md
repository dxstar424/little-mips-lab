# LAB5: 双发射

## 实验目标

在完成 LAB4 流水线的基础上，将处理器由**单发射改为双发射**。

- 双发射流水线应当能够以最高 **IPC=2** 的效率运行
- 特别注意避免实现成「伪双发射」（译码两条但只执行一条）

## 实验提示

1. **访存单端口**：Cache 和 MemCtrl 需适配；两路流水线在 MEM 阶段仲裁
2. **寄存器堆**：增加读/写端口；处理同一周期双写同一寄存器（年轻者覆盖）
3. **转发单元**：同时处理两条流水线的 EX/MEM 前推及跨 lane 前推
4. **分支预测器**：仍针对 slot0（PC）分支；需考虑双发射下的延迟槽
5. **双 ID 冒险**：同一发射包内 RAW、slot0 LW → slot1 依赖等
6. **冲刷**：误预测时 IF/ID 双路清空；延迟槽指令保留执行
