# 计组课程实验介绍

## 实验介绍

### 目标
紧贴课程大纲，由浅入深地带领同学们通过动手练习，深入理解课程中的体系结构相关知识，让同学们在课堂上学到的抽象概念在实验中得到验证。

### 软件 Lab
- 侧重模拟与分析
- 用软件模拟硬件实现
- 通过分析工具观察应用行为，帮助同学深入理解硬件结构如何影响软件代码的性能

### 硬件 Lab
- 侧重逻辑实现与电路架构
- 帮助同学们真正实现一个能运行起来的 CPU 原型

## 硬件 Lab 路线

从基础流水线开始，逐渐搭建一个高性能、支持 MIPS 指令集的处理器内核。
实验采取循序渐进的模式，大约每 3 周完成一个阶段性的性能提升。
最终实现一个能参加"龙芯杯"的 CPU 原型（完成LAB1-5大致可获得个人赛三等奖）。

### 各 Lab 内容

| Lab | 周期 | 内容 |
|-----|------|------|
| Lab1 | 3周 | 补全基础5级流水线：实现 Decode、ALU、Forward 模块 |
| Lab2 | 3周 | 多周期访存：实现 MemCtrl（访存控制器）、地址映射、写缓冲 |
| Lab3 | 3周 | 实现指令 Cache（数据 Cache 可选），写回策略 |
| Lab4 | 3周 | 实现分支预测 |
| Lab5 | 3周 | 实现双发射 |
| Lab6 | 4周(可选) | 实现 Tomasulo 算法及其他优化 |

---

## 硬件 Lab 与软件 Lab 的区别

- 硬件 Lab 使用 **VHDL/Verilog** 语言实现，是软件层的物理实现，相比软件 Lab，更加注重对时序的理解
- 硬件 Lab 所实现的处理器更为简单，但**调试更为复杂**
- 软件 Lab 需要实现 3 层 Cache 和多种分支预测，硬件 Lab 只要求完成 1 层 Cache 和一种动态分支预测
- 硬件 Lab 以**运行效率**为参考标准

## 龙芯杯

全国大学生计算机系统能力培养大赛（CPU设计赛），简称"龙芯杯"。
面向全国高校本科生的大型赛事，以自主设计"一个通用CPU、一个操作系统核心、一个编译系统"为总体目标。

### 评分
- **功能测试**：实现支持 MIPS 或 LoongArch32 指令集的 CPU，并成功运行大赛提供的 MIPS 监控程序
- **性能测试**：用监控程序加载基准测试程序并运行，以测试程序执行时间为性能评价依据
- **总成绩 = 功能测试得分 + 性能测试得分**
