# LAB1: 补全基础5级流水线

## 实验目标

安装 Vivado 2019 并下载 Lab1 文件包。实现基础 5 级流水线 CPU 的以下模块：
- **译码模块 Decode**
- **算数功能单元 ALU**（含乘法计算和分支跳转判定）
- **转发单元 Forward**

部分阻塞逻辑以及 PC 跳转逻辑已经在 core 中实现，请仔细阅读，避免重复实现。

本次实验需完成**龙芯杯 MIPS 赛制下 C1, C2, C3 的所有指令**。

---

## 何为流水线（5级）

| 阶段 | 功能 |
|------|------|
| 取指（Fetch） | 从内存中读取指令，使用程序计数器（PC）作为内存地址 |
| 译码（Decode） | 从寄存器中读取用于运算的数据 |
| 执行（Execute） | ALU 执行当前指令，计算内存引用的有效地址，可能设置条件码 |
| 访存（Memory） | 将数据写入内存，或从内存中读取数据 |
| 写回（Write back） | 将结果写入寄存器 |

## 实验流程

### 1. 使用 Vivado 新建项目
- 打开 Vivado 2019，点击 Create Project
- 选择 RTL Project
- 添加实验相关文件
- 芯片型号选择 **xc7k70tfbv676-1**

### 2. 仿真与测试
- 打开 `tb.sv`，将 `BASE_RAM_INIT_FILE` 修改为测试文件的路径
  - 测试文件为 `labf.bin` 或 `testfile.bin`
- 点击 Run Simulation → Run Behavioral Simulation
- 仿真时会读取文件来初始化 BaseRAM

### 3. 仿真结果验证
- 在 Scope 下找到 `tb/dut/core/ref`
- 右击 `regs` 信号，Add to Wave Window
- 使用"重启"按钮后 Vivado 会追踪 CPU 寄存器值
- **实验依据 regs 的仿真波形来判断 CPU 实现的正确性**
